# Conflicts - Charter Schedule Checker

A mobile-friendly web application designed to check for scheduling conflicts against live events in [Charter](https://charter-ivory.vercel.app).

## Features
- **Mobile-First Design**: Optimized touch targets and responsive layout for phones.
- **Live Sync**: Directly connects to Charter's Firestore database to fetch all family rides and library shifts.
- **Smart Conflict Detection**: Checks for any scheduled rides or OPL shifts on the selected date to identify possible scheduling conflicts.

## Usage
1. Select the **Date**.
2. Tap **Check for Conflicts**.
